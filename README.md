# PlatePal

PlatePal is an object-oriented restaurant discovery, rating, and social recommendation system developed in Java.

## Team Members

- Stefan Cheng
- Sunny Chen
- Nicole Zhang

## Core Features

- User registration and profiles
- Restaurant search and discovery
- Visited and Want to Try restaurant lists
- Restaurant ratings and reviews
- Personalized restaurant rankings
- Social following and friend activity
- Administrator restaurant management

## Technology

- Java
- Object-Oriented Programming
- UML Analysis and Design
